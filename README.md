# Reel Estate Lab

AI automatizációs bemutató weboldal ingatlanosoknak.

## Mit nyújt?

A Reel Estate Lab egy egyszerű AI leadkezelő rendszer koncepciója, amely segít az ingatlanosoknak:

- gyorsabban válaszolni az érdeklődőknek,
- rendszerezni a leadeket,
- automatikusan utánkövetni a komoly érdeklődőket,
- időt spórolni az adminisztráción,
- versenyelőnyt szerezni a piacon.

## Fájlok

- `index.html` - weboldal szerkezete
- `styles.css` - megjelenés
- `script.js` - demo és kalkulátor működése
- `assets/` - képek és vizuális elemek
